# Godox iT30Pro Manual Flash Helper

Offline-first manual flash exposure calculator for Nikon FE and Godox iT30Pro, with Sekonic L-308X calibration capture.

Features: ISO/aperture/distance and fill exposure calculators; N and W beam calibration; local JSON backup. Factory N-mode GN15 at ISO 100 and **provisional, unmeasured** W-mode loss of 1 EV. Does not replace a flash meter.

Install from GitHub Pages using Safari → Share → Add to Home Screen.
